About This Project

A hands-on cryptography system built for NWC3373 — implementing stream and block ciphers from scratch in Python.

Algorithm Descriptions

Stream Cipher Galois LFSR

The Galois Linear Feedback Shift Register uses a 32-bit internal state initialized from the user key. Each clock cycle outputs one bit using feedback polynomial x32 + x22 + x2 + x + 1. Keystream bytes are XORed with plaintext bytes, making encryption and decryption identical operations.

Block Cipher Custom Feistel

A 10-round Feistel network operates on 64-bit blocks split into two 32-bit halves. The round function is SIMON-inspired, combining rotated AND and XOR operations. A 128-bit master key expands into 10 subkeys, and PKCS#7 padding ensures arbitrary message lengths are supported.
